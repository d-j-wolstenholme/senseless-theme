# /build-page

Trigger the page-builder skill for end-to-end page construction.

## Usage

`/build-page [page name or URL slug]`

## Steps

Invokes the `page-builder` skill. Chains content-brief → create-section → seo-meta → image-process → metafield-populator → assembly → compliance-check.

Always confirms with me at each major step before proceeding.
