# Senseless Theme

UK aesthetics-focused topical preparation brand. Shopify theme built on Horizon base.

## Setup

1. Clone this repo
2. Copy `.env.example` to `.env` and fill in values
3. `npm install`
4. Run `/session-start` in Claude Code

## Key Files

- `CLAUDE.md` — Claude Code rules and protocol
- `docs/BRAND.md` — Design tokens
- `docs/COMPLIANCE.md` — UK compliance rules
- `docs/SECTIONS.md` — Section library index
- `docs/ARCHITECTURE.md` — Site architecture reference
- `DECISIONS-LOG.md` — Local mirror of Notion Decisions Log (active volume)
